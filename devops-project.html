DevOps Project — CI/CD Pipeline

A complete delivery pipeline for a small Python service. Every push is linted, unit-tested, packaged into a Docker image, pushed to a registry, rolled out to Kubernetes with zero downtime, and health-checked, with automatic rollback if anything fails.

ci.yml (excerpt)

on: { push: { branches: [main] } }
jobs:
  build-test-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install -r requirements.txt
      - run: flake8 .
      - run: pytest -q
      - run: docker build -t ghcr.io/susmithak98/hello-devops:${{ github.sha }} .
      - run: docker push ghcr.io/susmithak98/hello-devops:${{ github.sha }}
      - run: kubectl set image deploy/hello-devops app=...:${{ github.sha }}
      - run: kubectl rollout status deploy/hello-devops
