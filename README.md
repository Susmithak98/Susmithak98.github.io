# My Portfolio

A 3D portfolio site built with Three.js and hosted on GitHub Pages.

## Edit your details
Open `index.html` and find the `PROFILE` block near the top of the `<script>`. Change your name, links, projects, skills and experience there. Nothing else needs editing. If you leave a link as `""`, it is hidden.

## Deploy to GitHub Pages
1. Create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `avatar.png` (plus `resume.pdf` if you set one) and commit. Keep them side by side in the top folder.
3. In the repo, open **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, then choose branch `main` and folder `/ (root)`, and click Save.
4. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io`.

To update the site later, edit `index.html` and commit. The live site redeploys automatically.
